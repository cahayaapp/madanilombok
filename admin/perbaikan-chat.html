💬 Perbaikan & Pemulihan Chat

Gunakan halaman ini hanya ketika daftar percakapan hilang atau chat lama tidak muncul. Sistem membangun ulang indeks percakapan dari pesan yang masih ada dan dapat menggabungkan pesan dari backup JSON tanpa menimpa pesan yang lebih baru.

Penting: proses ini tidak menghapus ruang chat maupun pesan. Jalankan satu kali setelah upgrade. Jangan menekan tombol berulang saat proses masih berjalan.

1. Bangun Ulang Daftar Percakapan

Membaca pesan dan metadata chat yang masih ada, lalu membuat ulang pesan_inbox untuk setiap pihak. Cocok jika pesan sebenarnya ada tetapi daftar chat kosong.

2. Pulihkan dari Backup JSON

Pilih file Export JSON Realtime Database. Hanya node chat yang akan dibaca. Pesan dengan ID yang sudah ada tidak ditimpa.
