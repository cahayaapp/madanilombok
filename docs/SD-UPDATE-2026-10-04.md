# Pembaruan jadwal SD — 4 Oktober 2026

Pengguna memilih **Sheet1** pada `JADWAL PELAJARAN semester GANJIL 2026-2027.xlsx` sebagai jadwal resmi dan mengizinkan penambahan Miftahussurur. Sheet2 yang berbeda jam dan sebagian besar kosong tidak digabung ke jadwal operasional.

## Data yang disiapkan

- 238 slot pelajaran/kegiatan kelas I–VI untuk semester ganjil 2026/2027, ditambah 30 slot istirahat pada referensi terpisah.
- 214 jadwal SD lama dari PDF berstatus inactive dan tetap tersimpan beserta ID asal. Master aplikasi menyaring jadwal nonaktif agar tidak tampil ganda.
- 108 slot terhubung dengan SDM berdasarkan keterangan jabatan Sheet1. Mata pelajaran umum/BTA mengikuti Guru Kelas; penugasan mapel khusus mengikuti rincian kelas pada kolom jabatan. Tidak memakai kode guru Sheet2.
- 130 slot Tahfiz, Murajaah/Dhuha, Zuhur, Asar, Mahfuzat dan Pramuka belum memiliki pengampu per kelas yang eksplisit. Slot tetap ditampilkan dalam cakupan jadwal, tetapi ditandai needs_review sehingga tidak dianggap penugasan presensi/KPI guru.
- Enam Wali Kelas ditautkan ke ID SDM yang sudah ada. Ini tidak menambahkan assignment mentor individu.
- Miftahussurur ditambahkan sebagai `AMD-SDM-0087`, guru Bahasa Inggris kelas III–VI dan Fiqih kelas VI. Tidak mengarang biodata atau membuat akun Auth.
- Nama mapel dinormalisasi ke ID yang sudah ada. Zuhur, Mahfuzat dan Wushu dipisahkan dari label lama gabungan agar sesuai sumber.

Sel gabungan horizontal mengikuti rentang merge sumber. Sel kosong biasa tidak diisi otomatis. 24 slot Asar mempertahankan `endTime: "selesai"`. Pelajaran kelas VI Senin–Kamis pukul 14.30–15.30 beririsan dengan Asar mulai 15.00 pada sumber; empat peringatan tersimpan pada laporan, tanpa koreksi waktu sepihak.

## Penerapan

Master lokal dan rencana akun diperbarui. Jadwal SMP, mentor SMP, identitas siswa, keuangan dan data lain dipertahankan.

**Belum diterapkan ke database produksi atau dideploy.** Setelah kode tersedia, gunakan Admin → Import Data → **Terapkan Pembaruan SD**. Paket `seed/imports/sd-2026-2027-update.json` memperbarui jalur terkait saja, memeriksa unit/tahun jadwal lama sebelum menonaktifkannya, melewati jadwal lama yang tidak ada dan menolak ID orang yang bentrok. Akun aktif dengan staffId terkait memperoleh scope guru SD tanpa menghapus role lain. Import yang sudah ditandai berhasil tidak diulang otomatis. Tidak perlu menjalankan ulang bootstrap.

Scope akun dan master tetap memakai aturan pilot yang ada. Pembaruan bertarget atomik, tetapi pembacaan sebelum penulisan bukan transaksi bersyarat terhadap semua perubahan bersamaan; jangan menjalankannya bersama penyuntingan master/akun lain.

## Reproduksi dan pemeriksaan

Ekstrak dengan Python bundled: `scripts/extract-sd-update.py`, lalu jalankan `node scripts/import-sd-update.mjs` dan `node scripts/audit-master-data.mjs`. File sumber asli tidak diubah; ekstraksi menyimpan SHA-256, koordinat sel dan merged ranges.

72 tes lokal lulus, termasuk data SD, preservasi SMP/mentor, slot gabungan SMP, penggantian jadwal lama, import berulang dan scope akun. Uji UI memakai repository dalam memori, bukan Firebase produksi. Syntax JavaScript, parsing JSON dan hasil import berulang diperiksa.
